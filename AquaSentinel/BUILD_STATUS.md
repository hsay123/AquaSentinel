## Phases 1–6 — Backend Pipeline ✅ **CODE COMPLETE, CACHED DATA MISSING**

All pipeline modules are implemented and import correctly. Unit tests pass.

### Phase 1 — Ingestion + Water Mask ✅
- `ingestion.py`: GEE session, SCL-based cloud/shadow/cirrus mask, per-scene fetch
- `water_mask.py`: MNDWI + per-scene Otsu thresholding (recomputed per scene, not fixed)
- Test: Asserts water mask covers a sane fraction of AOI

### Phase 2 — Spectral Indices ✅
- `indices.py`: Four pure functions with documented formulas and scientific rationale
- NDTI = (B4−B3)/(B4+B3) — turbidity/suspended sediment
- NDCI = (B5−B4)/(B5+B4) — chlorophyll-a using red-edge
- FAI using B4/B8/B11 baseline-subtraction — floating algae/scum
- Texture anomaly: Sobel-based local variance within water mask
- All 13 unit tests pass

### Phase 3 — Time-Series Store ✅
- `timeseries_store.py`: Append-only Parquet store keyed (waterbody_id, zone_id, date)
- Schema: (waterbody_id, zone_id, date, scene_id, ndti, ndci, fai, texture_score, cloud_pct)
- BaselineStore: seasonal mean+std per zone, per calendar month

### Phase 4 — Anomaly Detection ✅
- `anomaly.py`: Rolling seasonal baseline (mean+σ per zone, per index, per calendar month)
- z-score flag when |z| > 2.0 (configurable)
- IsolationForest per water body on [NDTI, NDCI, FAI, texture]
- Fusion logic: statistical=high confidence, IF-only=needs review

### Phase 5 — Alerts + Explainability ✅
- `alerts.py`: Build Alert object per architecture.md §3 schema
- `explain.py`: Deterministic template filling from actual computed values
- Banned-phrase check enforced in code (constraint 5)
- LLM polish pass with fallback to raw template (`generated=false` pattern)

### Phase 6 — API ✅
- FastAPI routers matching architecture.md §4
- `/ingest/run?live=false` reads from cached Parquet (demo mode)
- `/ingest/run?live=true` calls GEE directly (logged/labeled as live path)
